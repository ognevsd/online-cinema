# Тест план

Функциональными тестами необходимо проверить работу основных ручек приложения.

## `films/`

1. Проверить что количество возвращаемых значений совпадает
2. Проверить сортировку по `imdb_rating`
3. Проверить пагинацию
4. Проверить фильтрацию по жанру

## `films/search`

1. Проверить что находятся существующие фильмы
2. Проверить что не находятся не существующие фильмы
3. Проверить пагинацию

## `films/{film_id}

1. Проверить что находятся существующий фильм
2. Проверить что не находятся не существующий фильм

## `genres/`

1. Проверить что количество возвращаемых значений совпадает
2. Проверить пагинацию

## `genres/{genre_id}`

1. Проверить что находится существующий жанр
2. Проверить что не находится не существующий жанр

## `persons/search`

1. Проверить что находится существующие люди
2. Проверить что не находится не существующие люди
3. Проверить пагинацию

## `persons/{person_id}`

1. Проверить что находится существующий человек
2. Проверить что не находится не существующий человек

## `persons/{person_id}/film`

1. Проверить что находятся фильмы, с которыми связан человек
2. Проверить что не находятся фильмы, с которыми человек не связан
3. Проверить что ничего не находится, если человек не связан ни с одним фильмом
